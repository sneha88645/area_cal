⭐ AREA CALCULATOR – Python Program

This is a simple Python console-based program that allows users to calculate the area of different geometric shapes. The program runs in a loop, letting users perform multiple calculations until they choose to exit.

✅ Features

This program can calculate the area of the following shapes:

Square

Circle

Rectangle

Triangle

Each shape has its own inner loop so users can perform repeated calculations without returning to the main menu.

🧮 How It Works

The program displays a menu with options from 1 to 4.

The user selects a number to choose a shape.

For the selected shape, the program asks for required inputs (side, radius, length, breadth, base, height).

After each calculation, the user can choose:

✅ Continue calculating the same shape
